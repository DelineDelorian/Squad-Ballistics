# Выпуск обновления / Releasing

Программа — один файл `SquadBallistics.exe`. Автообновление работает так:

1. При запуске `.exe` читает `version.txt` из ветки **main**.
2. Если версия там **новее** `CURRENT_VERSION` в `updater.py`, скачивается
   `SquadBallistics.exe` из **последнего релиза** на GitHub и подменяет
   запущенный файл (после выхода программы), затем программа перезапускается.

Версии до 1.1.0 включительно обновляются по-старому: скачивают
`SquadBallistics.zip` и копируют из него папку `SquadBallistics`. Поэтому в
релизе лежат **оба файла**: `SquadBallistics.exe` и `SquadBallistics.zip`
(в нём та же программа в папке `SquadBallistics`). Оба собирает Actions.

Порядок важен: **сначала релиз, потом `version.txt` в main.**
Если сделать наоборот, программа скачает старый файл из прошлого релиза, и
обновление будет запускаться при каждом старте.

## Тестовая сборка (ничего не публикует)

* Локально: `build.bat` → `dist\SquadBallistics.exe`.
* Через GitHub: любой push в ветку запускает Actions → **build-windows**,
  готовый exe лежит в разделе **Artifacts** этого запуска.
  Релиз при этом не создаётся, пользователи ничего не получают.

## Публикация новой версии

1. Поднять версию в двух местах (тест проверяет, что они совпадают):
   * `version.txt` → например `1.3.0`
   * `updater.py` → `CURRENT_VERSION = "1.3.0"`
2. Обновить `RELEASE_NOTES.md` — это текст релиза на GitHub.
3. Закоммитить и запушить в рабочую ветку, дождаться зелёного **build-windows**.
4. Создать тег на этом коммите и запушить его:
   ```
   git tag v1.3.0
   git push origin v1.3.0
   ```
   Actions соберёт exe и опубликует релиз `v1.3.0` с `SquadBallistics.exe`
   и `SquadBallistics.zip`.
   Если пушить теги нельзя: GitHub → Actions → **build-windows** →
   *Run workflow*, выбрать ветку и включить **publish_release** — тег
   `v<version.txt>` и релиз создаст сам Actions.
5. Убедиться, что релиз появился и в нём оба файла.
6. Только после этого влить ветку в **main** (Pull Request → Merge).
   С этого момента пользователи начнут получать обновление.
